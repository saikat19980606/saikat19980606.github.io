## Publish to your existing GitHub Pages URL
GitHub username: `saikat19980606`
Repository: `saikat19980606.github.io`
Public website: `https://saikat19980606.github.io/`

1. Extract this ZIP.
2. Open the existing GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder.
5. Ensure `index.html` is at the repository root, not inside another folder.
6. Click **Commit changes**.
7. Keep GitHub Pages set to `main` and `/(root)` under **Settings → Pages**.
8. Wait for deployment, then open the public URL and hard-refresh with Ctrl+F5.

GitHub Pages is free for public repositories and serves static HTML/CSS/JS. It does not run PHP, MySQL or WordPress server-side features.
