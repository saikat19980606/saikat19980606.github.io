# Saikat Pahari — Free Portfolio Website

Responsive dark-premium portfolio made with plain HTML, CSS and JavaScript.

## Included
- `index.html` — website content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation, reveal effects and scroll progress
- `assets/` — add your portrait photo here

## Personalize before publishing
1. Add your photo as `assets/profile.jpg` (the site will show it automatically).
2. In `index.html`, replace `your.email@example.com` with your email address.
3. Replace the LinkedIn URL and WhatsApp URL with your actual profile/contact links.
4. Review the Experience section and add exact company names, job titles and dates.
5. Replace the sample project panels with screenshots and real project links.

## Publish free using GitHub Pages
1. Create/sign in to a GitHub account: https://github.com
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload the contents of this folder to the repository root. Keep `index.html` at the root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. After deployment, your public URL will be `https://YOUR-USERNAME.github.io/`.

Anyone with the link can view the site. GitHub Pages supports static HTML/CSS/JS, not PHP/MySQL or WordPress server-side features.
