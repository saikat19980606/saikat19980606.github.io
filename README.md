## Personalize before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email.
2. Replace `https://www.linkedin.com/` with your LinkedIn profile URL.
3. Replace `https://wa.me/` with your WhatsApp link, e.g. `https://wa.me/91XXXXXXXXXX`.
4. Add exact company names, job titles and employment dates in the Journey section.
5. Replace the illustrative project panels with your actual project screenshots, descriptions and links.

## Update your existing GitHub Pages repository
Your GitHub username from the shared screenshot is `saikat19980606`.
1. Open your repository: `https://github.com/saikat19980606/saikat19980606.github.io`
   (If you have not renamed it yet, rename the repository to `saikat19980606.github.io` under Settings → General.)
2. Click **Add file → Upload files**.
3. Open this extracted folder on your computer and select `index.html`, `style.css`, `script.js`, and the `assets` folder.

Anyone can open the public link. GitHub Pages hosts static HTML/CSS/JS. It does not run PHP, MySQL or WordPress server-side code.
