S. PAHARI CREATIVE — PORTFOLIO WEBSITE

FILES
- index.html: main website page
- styles.css: responsive layout and visual styling
- script.js: mobile menu, scroll reveal and active navigation
- assets/: logo, portrait, featured project visual and résumé PDF

UPLOAD TO HOSTING / CPANEL
1. Extract the ZIP file on your computer.
2. Open cPanel > File Manager > public_html (or the folder for your domain).
3. Upload the contents of the spahari-portfolio folder, not the outer ZIP folder.
4. Make sure index.html is directly inside public_html.
5. Visit your domain and refresh the page.

CUSTOMIZATION
- Update text and links in index.html.
- Replace assets/saikat-portrait.jpg with your preferred portrait if needed.
- Replace assets/premiers-apple-tea.jpg with a clean original project image when available.
- The contact links use the email and phone details provided in the résumé.
- The contact CTA opens the visitor's email application (mailto); it does not store form submissions.

This is a static HTML/CSS/JavaScript website. No database or build process is required.
